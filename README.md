# Terço

Aplicativo mobile do terço católico guiado por voz, para iOS e Android (Capacitor + React + Vite + TypeScript). Público: pessoas simples, idosas e crianças. Idioma: português do Brasil. Funciona offline, sem conta e sem coleta de dados.

## Documentos

- [Prompt para o Claude Code e plano de lojas](docs/prompt-e-plano-de-lojas.md): prompt completo de construção (etapas 0 a 6) e plano para App Store e Google Play.
